This folder contains the Day 4 work completed following the VSD RTL Design & Synthesis Workshop flow.

## Flow

For each experiment:

- RTL Verilog
- RTL simulation
- Yosys synthesis
- Yosys schematic / block diagram
- Synthesized netlist
- Gate-Level Simulation (GLS)
- GLS waveform

- Yosys
- SKY130 standard-cell library
